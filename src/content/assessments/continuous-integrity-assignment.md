## The task

Write a program to the assignment specification, under version control, and a
report describing it. The specification is released in the workshop in which the
assignment is introduced.

## What you submit

- the program's repository, including its full commit history
- a report of exactly 4,800 words

## Commits

A commit must be made in every hour from release to the due time.

## Availability for questioning

Students must be available for questioning at any time between 9:00 am and
3:00 pm on the due date. Questions are sent on Teams. A student who does not
respond to a question within ten minutes receives a mark of 0 for the
assignment.

## Submission

Submissions are accepted through Canvas. Submissions are accepted during
business hours only.

## Deductions

The following deductions apply.

| Condition | Deduction |
| --- | --- |
| Each hour in which no commit is made | 5% |
| A commit message longer than 72 characters | 1% per commit |
| A commit message shorter than 20 characters | 1% per commit |
| A report that is not exactly 4,800 words | 100% |
| Use of a font other than the prescribed font | 5% |
| A file name containing a space | 2% per file |
| A file name that does not contain the student number | 2% per file |
| A variable name of one letter | 1% per variable |
| A program that does not compile | 50% |
| A program that compiles with warnings | 50% |
| A question answered by email rather than on Teams | 5% per question |
| Each submission after the first | 20% |
| Submission more than 24 hours before the due time | 100% |
| A commit made at a time the student was timetabled in another class | 20% per commit |

The report's word count includes headings, captions, references, code listings
and appendices. The word count is determined by the marker. The prescribed font
is not listed.

Deductions are applied cumulatively. Deductions in excess of the available mark
are carried forward to the next assessment.
